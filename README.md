# 🎂 Happy 19th Birthday - Arifah Zakiyatul Khasanah

Website ucapan ulang tahun ke-19 untuk Arifah Zakiyatul Khasanah (29 Juni 2026) dengan desain modern ala Korea / K-pop aesthetic.

## ✨ Fitur

- 🎬 **Preloader animasi** - Loading screen yang cantik
- ✨ **Particles & Confetti** - Efek partikel bintang yang melayang
- ⏰ **Countdown Timer** - Hitung mundur ke tanggal 29 Juni 2026
- 🎂 **Interactive Cake** - Tiup lilin secara interaktif
- 💌 **Animated Letter** - Surat yang bisa dibuka dari amplop
- 📸 **Photo Gallery** - Galeri untuk foto kenangan (bisa diganti)
- 🎵 **Background Music** - Melodi Happy Birthday
- 💙 **Heart Rain** - Animasi hujan emoji di bagian akhir
- 📱 **Responsive Design** - Tampil sempurna di HP & Desktop

## 🎨 Theme

- **Warna**: Biru, Putih, Hitam
- **Font**: Nanum Myeongjo (Korean), Outfit (Modern), Dancing Script (Elegant)
- **Style**: K-pop aesthetic, Glassmorphism, Dark mode

## 📸 Cara Ganti Foto Gallery

1. Siapkan 6 foto (format .jpg/.png)
2. Taruh di folder `assets/gallery/`
3. Edit file `index.html`, cari bagian gallery
4. Ganti `<div class="gallery-placeholder">` dengan `<img src="assets/gallery/foto1.jpg" alt="...">`

## 🚀 Deploy

### Vercel
1. Push ke GitHub
2. Connect repo di [vercel.com](https://vercel.com)
3. Deploy otomatis!

### GitHub Pages
1. Push ke GitHub
2. Settings → Pages → Source: main branch
3. Selesai!
